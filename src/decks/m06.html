The fork: one cause, two arrows out

Imagine smoking has no effect on TB death: no arrow between them.

Alcohol use is a common cause.

Drinkers smoke more, and drinkers die of TB more.

Will smokers still die of TB more often? Guess before the next slide.

The fork: a common cause with arrows to exposure and outcome. Deliberately no arrow from smoking to TB, so any association we find is pure confounding.

What stratifying did, in the diagram

The path Smoking ← Alcohol → TB death carries association: it is open.

Comparing within levels of alcohol puts alcohol in a box: we adjust for it. The path is now blocked (dashed).

Red means a non-causal path that is open and biasing the result. Dashed means blocked. These conventions are the same in Lab 2.

Giving it names

  • Back-door path: a path that starts with an arrow into the exposure. Smoking ← Alcohol → TB death.
  • Confounding: association that flows through an open back-door path.
  • Confounder: a variable that, adjusted for, blocks a back-door path. Here, alcohol.

Confounding is defined by the diagram, not by a statistical test.

Modern Epidemiology, 4th ed., chapter 12. Greenland S, Pearl J, Robins JM. Epidemiology 1999;10:37-48.

This is the structural definition. It agrees with the potential-outcome idea from Module 2: an open back-door path is what makes groups non-exchangeable.

Same men as Module 2. In this teaching example the stratum ratios are equal; in real data they differ somewhat, and we need one summary number.

One number for everyone: standardise

Ask: what would the risk be if all 100 men smoked, keeping the real mix of 40 drinkers and 60 non-drinkers?

If all smoked: 0.4 × 0.75 + 0.6 × 0.15 = 0.30 + 0.09 = 0.39

If none smoked: 0.4 × 0.25 + 0.6 × 0.05 = 0.10 + 0.03 = 0.13

Standardised risk ratio = 0.39 / 0.13 = 3.0

These are exactly the two futures of Module 1, rebuilt from data we could actually observe, once alcohol is accounted for.

Modern Epidemiology, 4th ed., chapter 18, Stratification and Standardization.

Standardisation is a weighted average of the stratum risks, with the whole population's mix as weights. It answers the counterfactual question directly.

Five ways to adjust, one idea

MethodWhat you do
StratifyCompare within each level of alcohol
StandardiseCombine the strata with the population's weights
RestrictStudy only non-drinkers
MatchPair each smoker with a non-smoker who drinks the same
RegressionPut alcohol in the model

All five hold alcohol fixed while smoking varies. All five block the same path.

Students often think regression is different in kind. It is the same move: comparing at fixed levels of the covariate.

A warning about the old rules

"Associated with both exposure and outcome"

A mediator and a collider (Modules 7 and 8) are associated with both too.

"It changed the estimate by 10%"

Adjusting for a mediator or a collider changes the estimate too, in the wrong direction.

Only the diagram can tell a confounder from the other two.

Hernán MA, Hernández-Díaz S, Werler MM, Mitchell AA. Am J Epidemiol 2002;155:176-84.

What to carry forward

A fork, a common cause, opens a back-door path and creates confounding.

Adjusting for the common cause, by any method, blocks the path. Stratum and standardised ratios show it in numbers.
